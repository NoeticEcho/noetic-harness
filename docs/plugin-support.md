# Support: the noetic-harness plugin

Questions, problems and ideas about `noetic-harness`, the Claude plugin in
[`priv/plugin/`](../priv/plugin/README.md), go to the repository's issues:
<https://github.com/NoeticEcho/noetic-harness/issues>.

Say which version of the plugin (`priv/plugin/.claude-plugin/plugin.json`)
and of Claude Code you run, whether `noetic-harness` is installed and which
version (`noetic-harness --version`), what you asked Claude, and what
happened.

Issues are read and answered by the maintainers as time allows. There is no
promised response time and no paid support. A fix lands on `main` and reaches
the plugin directory with the next release.

**Before you ask:** a slash skill that says the engine is missing is working
as intended. The plugin does not contain the engine; the
[plugin's README](../priv/plugin/README.md) says what works without it, and
the [repository's README](../README.md) says how to install it.

**Security problems** are not issues: report them privately, through
GitHub's private vulnerability reporting on the repository (the **Security**
tab, then **Report a vulnerability**), as [SECURITY.md](../SECURITY.md) says.

See also: [Privacy](plugin-privacy.md) and [Terms](plugin-terms.md).
