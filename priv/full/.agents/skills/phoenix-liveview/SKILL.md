# LiveView

- Understand disconnected/connected lifecycle phases.
- Load data and subscribe at the correct lifecycle boundary.
- Prefer streams for large dynamic collections when appropriate.
- Use to_form and proper form boundaries.
- Keep domain logic in contexts/domain modules.
- Keep HEEx component APIs explicit and small.
- Test interactions with LiveView test helpers.
- Use Phoenix Storybook for reusable visual components when useful.
- Use Tidewave first for running-app diagnostics.
